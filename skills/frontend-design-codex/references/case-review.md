# 从印刷样张到《下潜》：如何审一张互动落地页

## 先用一句话定义访客要做的事

印刷页的读者从社刊来领取柑橘样张。首屏要回答“我会拿到什么，怎样领取”。实际样张放在下载按钮旁边，“两页 A5 PDF”说明交付内容，点完核对下载文件。音乐页的读者要试听。把播放键放在曲名旁，第一次点击就应听到声音，播放、暂停和跳段都应有可见反馈。

## 找准问题再改

| 看到的现象 | 能解释现象的设计决定 | 怎样复核 |
| --- | --- | --- |
| 页面完整，缩小后却认不出主体 | 选一件能说明内容的实物、图像或演示。印刷页放大真实印样，音乐页为曲名和水母分别留出空间。 | 桌面与手机各截一张静帧，检查主体轮廓、标题和主操作。看不清的印刷网点可单独放大。 |
| 多个按钮像彼此独立的操作 | 根据用途安排形状。下载是一个文字动作；成品、橙墨、靛蓝是同组选择；纸张保留直角。 | 用手指或键盘选中另一个色版，确认能分辨当前选择和下一步操作。圆角数值由项目决定。 |
| 音乐开始了，最醒目的画面仍与声音无关 | 选一种可感知的对应关系，让真实频段控制可见变化。 | 同一乐段切换高低频，再暂停，分别核对听感、频谱和停止后的状态。 |
| 形变对上了节拍，主体却显得僵硬 | 观察动作顺序。《下潜》把伞缘收拢、身体滑行、触手拖曳分开处理，为身体移动留出背景。 | 统一音乐时间和画面尺度，先按正常速度看，再慢放比较根部与末端。单张封面能表现的侧转与遮挡有限。 |
| 桌面细节丰富，手机上看不到动作 | 为小屏重新取景，把动作的起点和跟随部位同时留进画面。 | 对照同一秒的桌面和手机录像，并在小屏上实际触发主要动作。 |
| 静止封面也下载动画素材 | 区分首屏必需的图像与进入互动后才用的图层。先呈现完整封面，后台准备动效时让音乐继续播放。 | 关闭缓存，分别记录首次进入、开始播放和减少动态效果下的网络请求；再模拟图层缺失。 |

## 哪些结论需要真实读者

浏览器可以验证文件是否正确、声音是否开始、进度是否停住、频段是否改变和背景是否稳定。审美偏好、动作是否可信、访客愿不愿继续听，需要读者反馈。做版本对照时固定音频和播放位置，隐藏版本名称，问“哪一瞬间让你觉得自然或不自然”。下一轮围绕这个时刻改一个变量，再看判断有没有改变。

## 用社区预约页检验办事效率

预约页把地点放到标题旁，时长与费用放到日期旁，接修范围放进物品选择器。手机首屏给可选时段留出位置。满额日期仍可查看原因。改日期时清空原时段，保留仍然有效的维修物品。核对页同时展示日期、时间与物品，并提供返回改选入口。

验收时先试一次选错：进入满额日期，换到另一日，漏选物品，补全后再改约。核对最终回执、刷新恢复的内容，以及窄屏下第一个可选时段的位置。自动化走通只能确认路径可用；文字是否让人一次读懂，要交给第一次使用页面的人判断。

## 从静态参考到动效验证

看视觉参考时先指出一个可见细节，再解释它如何帮助访客完成当前任务。馨子的网页 UI 画板里，白底表单用蓝色定位步骤和提交入口；深色数据页把大面积留给曲线。修理铺借用了前者的信息层级，用灯罩的黄色表示当前选择，深绿标出核对入口。参考图只能支持静态构图判断。来源见 [网页 UI 画板](https://www.pinterest.com/zhang_yaxin/%E7%BD%91%E9%A1%B5ui/) 与 [Cao Hao 的社区二手家具概念](https://dribbble.com/shots/6376698-Used-furniture-social-e-commerce)。

给物理动作画四个关键姿态：准备、发力、惯性滑行、末端跟随。逐拍说明谁先动、谁后动、在什么参照物上能看出来。摄影机跟拍可能抵消移动距离；同时查看固定机位与成品裁切，在相近收缩阶段追踪伞盖的一处纹理。以浏览器画面记录位移，正常速度带声回放检查节奏，静音再看能否读懂动作。手机上单独检查起点和终点是否都在安全画幅内。

办理型页面的动效应回答“刚才的选择改动了什么”。切换日期时只提示新时段，保持日期和主按钮的位置稳定。减少动态效果时直接显示最终状态。审美偏好和生物运动的可信度需要观看者评价。

## 幕布的重量与包厢的入口

《月亮失物处》的拖动先收掉绳上的余量，再经吊轨带动布身和金边下摆。观察金边能分辨下摆起步和停住都比上沿晚。两片幕布外侧固定，折痕随布料一起收拢。验收时固定机位，在拉绳中途停住，再试短拉松手、拉过开幕点松手以及触摸被取消，逐次检查布料和绳结如何复位。拖动阈值与阻尼由材质、行程和屏幕尺寸决定。

七号包厢以栏杆和檐口接在台侧墙上，幕布从它前面掠过。看见座椅和金色灯盏之后，就能点楼座本身进入。原小样的图文弹窗能读信，却看不见穿过台口的过程。要表达进入一个地方，应从当下屏幕上的拱门取景，用室内的同一盏灯、同一把椅子交代目的地。返回时沿同一路径退出；从第二幕进入就回第二幕，并核对幕布状态、滚动位置和入口焦点。分别录制桌面与手机的完整往返，再检查减少动态效果时能直接抵达这两个状态。
